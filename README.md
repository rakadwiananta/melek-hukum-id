# Wacana Hukum

Portal hukum Indonesia terpercaya dengan artikel, regulasi, dan solusi hukum terkini.

## Fitur

- Artikel hukum terkini
- Kamus istilah hukum
- Template dokumen hukum
- Konsultasi hukum online
- Anti-korupsi resources

## Teknologi

- Next.js 15
- TypeScript
- Tailwind CSS
- Supabase
- Vercel/Netlify

## Instalasi

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
